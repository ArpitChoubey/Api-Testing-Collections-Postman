# 🚀 How to Run

## Step 1

Clone the repository

```bash
git clone https://github.com/ArpitChoubey/Api-Testing-Collections-Postman.git
```

---

## Step 2

Open Postman

---

## Step 3

Import any collection

```
API Chaining.postman_collection.json
```

or

```
Student API.postman_collection.json
```

---

## Step 4

Configure Environment Variables (if required)

---

## Step 5

Run the collection

Using:

- Collection Runner
- Newman
- CI/CD Pipeline
